# Measured cases

[catalog.json](catalog.json) contains 13 concrete reading examples derived from the released experiment summaries. Each entry names the involved configurations, observation, and interpretation limit. They cover all four LIBERO suites, quality failures, the complete lambda sweep, random allocation, extreme compression, and codec tradeoffs.

Read the illustrated [case walkthrough](../../docs/CASES.md). Run `python scripts/verify_results.py` from the repository root to verify the underlying counts and measurement identities. These are numerical experiment cases; no demonstration videos or new closed-loop runs are claimed.
